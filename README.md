## Setup
Needs Python 3.9 or newer. The banknote data is already in `data/data_banknote_authentication.txt`.

Run everything below from the project root (the folder that contains `src/`, `scripts/` and `tests/`).

```
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
```
The only required packages are numpy and matplotlib. Jupyter is optional and only needed for the notebook.

## Run
Always use `python -m ...` (not `python scripts/...`), otherwise the `src` imports fail.

**1. Check that everything works (takes a few seconds)**
```
python -m tests.test_ann        # ANN checks
python -m tests.test_coupling   # fitness (ANN <-> PSO) checks
python -m tests.test_stats      # permutation test and Bonferroni checks
```
Each test prints `PASS` and the test name. Nothing is printed on failure except an error message.

**2. Train the ANN with PSO once**
```
python -m scripts.check_ann        # random weights, shows the accuracy before training
python -m scripts.train_ann_pso    # PSO training, prints train and test accuracy
```

**3. Experiments (Task 5)**
Each one prints tables with mean ± std over 10 runs and saves plots into `results/`. Each takes roughly 15 to 60 seconds.
```
python -m scripts.pso_experiments    # swarm size, coefficients, boundary handling
python -m scripts.ann_experiments    # hidden neurons, depth, activations, PSO-chosen activations
python -m scripts.extra_experiments  # informants, inertia, effect of the data split
```
`pso_experiments.py` runs the experiment chosen at the bottom of the file (edit the `__main__` block to switch). Results are seeded, so rerunning gives the same numbers. Running the experiments overwrites the plots in `results/`.

p-values in the ANN and extra experiments come from a paired permutation test (runs paired by seed) and the `p adj` column is Bonferroni corrected within each table.

**4. Notebook (optional)**
```
pip install jupyter
jupyter notebook notebooks/01_data_exploration.ipynb
```
Open it from the project root. It only explores the data and does not train anything.

## Layout
| File | Purpose |
|------|---------|
| `src/activations.py` | logistic, ReLU, tanh (+ leaky ReLU as an extra) |
| `src/ann.py` | `NeuralNetwork` class (forward pass, flat parameter get/set) |
| `src/data.py` | load CSV, stratified 70/30 split, standardisation |
| `src/metrics.py` | accuracy, precision, recall, F1 |
| `src/particle.py` | one PSO particle (velocity update, move) |
| `src/pso.py` | PSO swarm and main loop (Algorithm 39) |
| `src/coupling.py` | fitness(vector) = ANN training accuracy; extension: PSO also chooses hidden activations |
| `src/stats.py` | paired permutation test (runs paired by seed) + Bonferroni |
| `tests/test_ann.py` | ANN sanity tests |
| `tests/test_coupling.py` | coupling (fitness) tests |
| `scripts/check_ann.py` | end-to-end check with random weights |
| `scripts/train_ann_pso.py` | one PSO-trained run |
| `scripts/pso_experiments.py` | PSO experiments: swarm size, coefficients, boundary handling |
| `scripts/ann_experiments.py` | ANN experiments: architecture, activations, evolved activations |
| `scripts/extra_experiments.py` | informants, inertia, data-split variability |
| `results/` | saved plots (generated by the experiment scripts) |
| `notebooks/01_data_exploration.ipynb` | charts and checks of the banknote data (needs jupyter, optional) |
